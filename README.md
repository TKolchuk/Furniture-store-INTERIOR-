##  Интернет-магазин мебели «Интерьер»

>  **Учебный проект** по вёрстке адаптивного многостраничного сайта

Адаптивный сайт для продажи мебели и предметов интерьера. Проект демонстрирует навыки работы с семантической разметкой, адаптивным дизайном, методологией БЭМ и препроцессором SASS.

[Посмотреть демо на GitHub Pages](https://tkolchuk.github.io/Furniture-store-INTERIOR-/)  
[Макет в Figma](https://www.figma.com/design/Rp8z9Tz4vCClg1SpTMobu9/Online-store-website?node-id=196-425&p=f&t=FkCXd1YvZcseAeUC-0)


##  Возможности проекта

-  **Полная адаптивность**: корректное отображение на мобильных (<768px), планшетах и десктопах (≥1024px)
-  **Интерактивные элементы на чистом CSS**: плавные переходы, анимации при наведении, появление иконок «В корзину» и «В избранное»
-  **Модальное окно фильтрации**: кастомные радио-кнопки, чекбоксы с цветами, диапазон цен через `input[type="range"]`
-  **Страница корзины**: просмотр товаров, изменение количества, форма оформления заказа
-  **Семантическая разметка**: использование тегов HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)

## Технологии
В проекте использованы технологии: HTML, CSS (SASS), БЭМ, Git.
